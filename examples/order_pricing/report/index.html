How it is measured

plgauge reads the compiled source, places probes on every statement, decision and sub-condition and recompiles the code. The probes add no lines, so error messages keep their line numbers. Then the utPLSQL tests run, and the original code is restored.

NULL and short-circuit

Every sub-condition is counted as TRUE, FALSE or NULL. The probes return the value unchanged, so short-circuit evaluation and NULL semantics are preserved. MC/DC treats sub-conditions that were not evaluated as wildcards (unique cause with short-circuit).

Limits

Conditions in WHERE, ON and HAVING clauses are deliberately not instrumented, because that would change the execution plan. Dynamic SQL and code obfuscated with wrap are not measured. Hits from sessions of other users, and from parallel query slaves that run fewer than 1000 statements, are lost.
